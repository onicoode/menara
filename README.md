# Menara Rongsok

Game tower-defence piksel (HTML5 satu file, dibungkus jadi APK Android).

- Sumber game: `proyek-gradle/game-src/` (digabung dengan `proyek-gradle/tools/make_html.sh`).
- Proyek APK: `apktool-src/`.
- Catatan lengkap pengembangan dan cara build: [CATATAN-LANJUT.md](CATATAN-LANJUT.md).
- Menu Dev/Balancing: tekan ` atau F2 di dalam game.
- **Versi Godot 4.4 (target Play Store): [`godot/`](godot/README.md)**. Build Web/AAB lewat GitHub Actions.

Kunci tanda tangan (`kunci/`) sengaja TIDAK ada di repo. Simpan pribadi; APK baru hanya bisa menimpa yang lama bila memakai kunci yang sama.
