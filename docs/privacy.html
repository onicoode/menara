Kebijakan Privasi - Menara Rongsok

Menara Rongsok adalah game offline. Game ini tidak mengumpulkan, menyimpan di server, atau membagikan data pribadi apa pun.

  • Tidak ada akun, iklan, pelacak, atau analitik.
  • Game tidak meminta izin khusus (kamera, lokasi, kontak, dsb.).
  • Progres, profil, dan pengaturan disimpan hanya di perangkat Anda dan terhapus bila game dihapus.
  • Game tidak memerlukan koneksi internet untuk dimainkan.

Pertanyaan: hubungi pengembang lewat halaman repositori proyek di GitHub (onicoode/menara).
